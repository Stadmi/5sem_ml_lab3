# ЛР 3 — надёжность LLM в задачах машинного обучения

С. Д. Кузнецов, ИУ6-55Б.

## Материалы

- `lab_3.ipynb` — итоговый анализ: 14 разделов, 36 ячеек.
- `Отчет_лаб3_Кузнецов_ИУ6-55Б.docx` — отчёт с 16 таблицами и 8 рисунками.
- `data/` — ответы моделей для анализа, датасет, разбиение, бланки и протоколы запусков.
- `figures/` — 10 графиков из ноутбука.
- `results/tables/` — итоговые таблицы.

Основная карта показывает долю зачтённых ответов по типам и balanced accuracy
для E при 20 примерах. Дополнительная карта с баллами C и график запускаемости D
доступны в ноутбуке. Два ИИ-проверяющих оценивали
анонимные ответы C/D в отдельных сессиях. Заполненные бланки сохранены в
`data/independent_review_*.json`. Старые условные оценки C/D сохранены для истории.
Итоговые зачёты автора для C читаются из `data/c_final_decisions.csv`.
Ноутбук выводит их рядом с баллами проверяющих в `results/tables/c_review_details.csv`.
В таблицах также есть тариф Alice и снимок памяти Qwen.

## Воспроизводимость

Первый коммит в сокращённой истории воспроизводит гипотезы и файлы протокола
из исходной фиксации `731d25ddc60ecd0d8e9df29de541a8d8410b108e` (2026-11-19T02:01:34+03:00).
Новые коммиты созданы при сокращении истории. В журнале и в
`data/preregistration.lock.json` указаны исходный хэш и исходное время фиксации.
В чистой копии Git может не найти исходный коммит. При этом ноутбук сверяет
контрольные суммы протокола с файлом фиксации.

Для повторного анализа установите зависимости из `requirements.txt` и выполните
все ячейки `lab_3.ipynb`. Ноутбук читает сохранённые данные без запросов к API.
